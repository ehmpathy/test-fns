# case=8 — the clamp derives the path, never hardcodes it

> cell 17 · the adopter's seam · **feel** happy · **care** critipath — the wish's *tie that bites*

## the narrative

kai, downstream in `rhachet`, writes the regression clamp that proves the leak is closed:

```ts
import { getOneTempDirRoot, isTempDir } from 'test-fns';

const { pathPhysical } = getOneTempDirRoot();
const countBefore = readdirSync(pathPhysical)
  .filter((name) => isTempDir({ path: name }))   // ⚠️ NOT a raw entry count — see below
  .length;
// ... run the suite ...
expect(countAfter).toEqual(countBefore);
```

> ⚠️ **the `isTempDir` filter is a REQUIREMENT, not a nicety.** the
> contained dir holds **two non-fixture files by construction**, written on every run:
>
> ```ts
> findsertFile({ path: path.join(pathPhysical, 'readme.md'),  content: TEMP_README_CONTENT });
> findsertFile({ path: path.join(pathPhysical, '.gitignore'), content: '*\n' });
> // genIsolatedTempInfra.ts:61-70
> ```
>
> so a naive `readdirSync(pathPhysical).length` reads **2** on a pristine dir, and **3+** once
> [case=12](./1.vision.experience.case=12.teardown-never-ran-next-run-says-so.md)'s run markers exist.
> a clamp that counts raw entries is not merely off by a constant — it would **count a marker as a
> leaked fixture** and report a failure on a run that reclaimed every dir it made.
>
> `isTempDir` is already in the contract (`src/contract/index.ts:10-13`), so the filter costs the
> consumer no new import. **the export's whole purpose is that a consumer derives rather than
> guesses — and an unfiltered count is a guess about what lives in that directory.**
>
> the name is **`getOneTempDirRoot`** — `rule.require.get-set-gen-verbs` mandates cardinality of
> `get` only, and the local `genTempDir`/`isTempDir` sit on a different branch, so there is no clash
> to settle.

six weeks later #66 lands, and the contained dir moves from
`/tmp/test-fns/rhachet.beav.some-branch/.temp/` to `/tmp/test-fns/rhachet/.temp/`.

**kai's clamp holds, and kai never learns that the path moved.** that is the deliverable.

## the failure this exists to prevent

had kai written the literal instead:

```ts
const dir = `/tmp/test-fns/${basename(gitRoot)}/.temp`;   // 👎
```

then after #66 that path holds zero dirs. `countBefore = 0`. `countAfter = 0`. the assertion
passes. **the clamp is green and blind** — it now measures an empty directory that no run writes
to, while the real contained dir leaks unobserved.

the wish names this precisely:

> a clamp that hardcodes either literal counts **0 before and 0 after** once the other is live —
> green, and blind.
>
> that is the `1,786 orphan dirs accrued under a green clamp` precedent a third time.

**a third time.** that is why the export is in scope for this tree rather than deferred with #65:
without it, the acceptance criterion "measured by a count before and after" cannot be written by
anyone downstream in a way that survives the next change.

## the shape of the export

reuse the extant vocabulary rather than mint a new word. `genIsolatedTempInfra` already returns
`{ pathPhysical, pathSymlink }` (`src/infra/isomorph.fs/genIsolatedTempInfra.ts:40`) — the two
paths already have canonical names in this repo. the export surfaces that same pair:

| path | what it is | who wants it |
|---|---|---|
| `pathPhysical` | `/tmp/test-fns/{scope}/.temp` | a clamp that counts; a human who will `cd`; a test that needs a cwd outside any git repo |
| `pathSymlink` | `@gitroot/.temp/genTempDir.symlink` | discoverability, which is its stated purpose |

**one export serves three consumers** — the clamp (`case=8`), the hold message
([case=6](./1.vision.experience.case=6.hold-keeps-them-and-says-where.md)'s `at:` line), and the
reclaim itself. that answers the wish's open question *"is one export enough?"* — yes, provided it
yields **both** paths rather than picks one for the caller.

### the bonus it lands, unasked

`pathPhysical` is outside any git repo. that is the entire capability #65 asks for — a cwd for a
"not a git repo" probe. so this export **retires #65's need without a second design**. whether the
issue closes is the maintainer's call, per the wish.

## the timeline

```gherkin
given('[case8] a consumer that writes a before/after count clamp', () => {

  when('[t0] the consumer asks the library where dirs live', () => {
    then('it yields the physical path', () => {
      expect(getOneTempDirRoot().pathPhysical).toMatch(/^\/tmp\/test-fns\/.+\/\.temp$/);
    });

    then('it yields the symlink path too', () => {
      expect(getOneTempDirRoot().pathSymlink).toContain('.temp/genTempDir.symlink');
    });

    then('the physical path is where genTempDir actually writes', () => {
      const dir = genTempDir({ slug: 'probe' });
      expect(realpathSync(dir)).toContain(getOneTempDirRoot().pathPhysical);
    });

    then('the physical path sits outside every git repo — retires #65', () => {
      expect(findGitRootUpwardFrom(getOneTempDirRoot().pathPhysical)).toEqual(null);
    });
  });

  when('[t1] the scope key changes underneath the consumer (the #66 move)', () => {
    // ⚠️ the population is MINTED here. a `toBeGreaterThan(0)` against a dir
    //    that NO step put a single entry into is simply false on a clean dir,
    //    and the "bites" intent it carries is then produced by the walk at no
    //    point. an anti-assertion needs its population established more
    //    urgently than a positive one does — it exists to fail loudly, and a
    //    claim that rests on an unestablished count fails for the wrong reason.
    const pathOld = useThen('the consumer notes the OLD literal path', () =>
      getOneTempDirRoot().pathPhysical,
    );
    const RAfter = useThen('the scope re-keys, and a run writes at the NEW path', () =>
      mintRun({ afterScopeMove: true }),
    );

    then('the export follows the move', () => {
      expect(getOneTempDirRoot().pathPhysical).toEqual(whereGenTempDirNowWrites());
      expect(getOneTempDirRoot().pathPhysical).not.toEqual(pathOld);
    });

    then('a clamp built on the export still counts real dirs, not zero', () => {
      expect(countTempDirs(getOneTempDirRoot().pathPhysical, { run: RAfter }))
        .toBeGreaterThan(0);
    });

    then('while the hardcoded literal counts ZERO — the bite, made visible', () => {
      // this is the whole of case=8 in one line: the literal is not WRONG,
      // it is SILENTLY EMPTY, so a clamp built on it reads 0 before and 0
      // after and reports a guarantee it never measured.
      expect(countTempDirs(pathOld, { run: RAfter })).toEqual(0);
    });
  });

  when('[t2] the consumer runs its full before/after clamp', () => {
    // ⚠️ these three are bound here, never free variables. this is the case
    //    that TEACHES a consumer to write a clamp, so an unbound term here is
    //    a pattern they would copy.
    //    note the count filters through isTempDir: readme.md and .gitignore
    //    live in every contained dir (genIsolatedTempInfra.ts:61-70), so a
    //    raw readdir reads 2 on a pristine one.
    const { pathPhysical } = getOneTempDirRoot();
    const countBefore = useThen('the clamp counts before the run', () =>
      countTempDirs(pathPhysical),
    );
    const R = useThen('the consumer\'s suite runs', () => mintRun());
    const dirsMadeInRun = useThen('it made fixture dirs', () =>
      countTempDirs(pathPhysical, { run: R }),
    );
    const countAfter = useThen('the clamp counts after the teardown', () =>
      countTempDirs(pathPhysical),
    );

    then('before and after agree, and both are non-trivial', () => {
      expect(countAfter).toEqual(countBefore);
      expect(dirsMadeInRun).toBeGreaterThan(0);  // the clamp BITES
    });
  });
});
```

## `[t2]`'s second assertion is the whole point of this case

`expect(countAfter).toEqual(countBefore)` passes trivially when both are zero. **the clamp must
also prove that dirs were actually made and actually reclaimed** — otherwise it is the green-and-
blind clamp this case exists to forbid.

per `rule.require.clamp-edge-cases`, the execution stage owes a demonstration that this clamp
**bites**: revert the reclaim, watch it go red; restore it, watch it go green. a clamp nobody has
seen fail is a guess.

## 🟠 the name was a fulcrum, and it is settled: `getOneTempDirRoot`

the narrative says `getOneTempDirRoot`, the whole timeline calls `getOneTempDirRoot()`, and the
yield's register answers question 1 as `getOneTempDirRoot`. a best-guess of **`getTempDirRoot`**
must survive nowhere beside them: one artifact that settles a name and rejects it in the same file,
on the wish's own *tie that bites*, hands a consumer the wrong one.

**the decision, and it holds:** `rule.require.get-set-gen-verbs` mandates cardinality on `get`.
the neighbours that seem to argue against it — `genTempDir`, `isTempDir`, `genTestUuid` — sit on
the `gen`/`is` branches, which the rule does not govern that way, so there is no clash to trade
against. and the export yields **one** root object seen two ways
(`{ pathPhysical, pathSymlink }`), so `One` is right on the merits rather than merely compliant.

> **the lesson.** a *"flagged, not settled"* section is a **copy of a decision's state**, and it
> goes stale the moment the decision is made elsewhere. the repair is not a more careful sweep:
> **when a fulcrum closes, its flag must be deleted, never annotated** — a resolved fulcrum that
> still sits beside its own resolution is worse than an unflagged one, because a reader cannot tell
> which text is current.
