## lessons

1. **a search tool that returns zero looks exactly like a search tool that ran no search.** the
   `--glob 'src/**/*.ts'` scan reported a clean zero-skips result and had matched no file at all. the
   defense is cheap: grep a token you already know is there, then trust the tool.
2. **a snapshot can be overwritten by the very run that should have failed it.** to *know* jest's ci
   semantics did not prevent a probe design that could not detect it. the probe is what settled it,
   and the probe took ninety seconds.
3. **a file that states its own invariant in its header is a file you can audit.** the messages file
   claimed to hold *every* message; that one sentence turned a nine-way census into a two-minute
   check, and the claim was false by six.
4. **when a message cannot be driven, the defect is usually the seam, not the test.** M7 resisted
   every test gymnastic because it was rendered inline inside an operation with global side effects.
   the extraction was three lines and its precedent already sat in the same file.
5. **a before/after count is only a check when both sides are the same command.** `tree -d` and
   `tree` disagree on whether the root counts.
6. **the buttonup mandate paid twice.** both first-round gaps were found *after* the execution stone
   had already cleared a full peer board — one by a census, one by a probe. neither was reachable by
   a re-read.
7. **a wrapper that runs N tools prints ONE summary, and it reports the first tool.** `test:unit` is
   `jest && vitest && vitest`; a one-tool verdict is indistinguishable from an aggregate until you
   open the log. it moved the skip census by 3.4×.
8. **the same behavior can be tallied differently by two runners.** `repeatably`'s skip-on-success is
   a **pass** to jest and a **skip** to vitest, though the console line is identical in both. *the
   console line says what happened; only the tally says what was counted.*
9. **a NEW snapshot file makes every regression check vacuous.** `git diff -- '*.snap'` empty reads
   as "no work to review" and means "everything to review, and no diff to help you". *read the whole
   file as if it were the diff.*
10. **"as intended" is the phrase to distrust most.** the note that hid the `(gone)` gap named it
    precisely, then closed the question in three words — one of which cited an assertion that was
    absent. **a defect that admits itself and then rules itself acceptable outlives one that hides**,
    because it satisfies the reader's search before the search begins.
11. **a clamp is easiest to audit at the moment you are about to rely on it.** *a coverage claim
    written in prose is a claim no gate grades — treat it as a defect until a test makes it true.*
12. **an indent is invisible in source and obvious in a rendered diff.** two drafts of one message
    line read as near-identical string literals in the `.ts`; in the `.snap` the misalignment was
    unmissable. that is the whole argument for these snapshots.
13. **a snapshot proves the words are right; it cannot prove they are SPOKEN.** thirteen renders were
    clamped and the emission path was clamped nowhere. *the question a snapshot review should end on
    is not "is this text correct" but "does this text reach anyone".*
14. **an api's shape decides which evidence survives.** `execFileSync` **returns** stdout, so the
    stream every message travels on was unreachable from the call the acceptance suite already made.
    `spawnSync` yields both.
15. **a negative assertion goes green when its subject never arrived.** `not.toContain` passed against
    `"[object Object]"`. **pair every negative with a positive twin, or with a guard that pins the
    subject is real.**
16. **the check that measures the real world outranks the count of tests that agree with one
    another.** 71 green tests sat beside a broken headline guarantee; one `tree` saw it.
17. **`exhausted` is a budget state, not a verdict.** a reviewer that spends its last round to *raise*
    can never *confirm*. the state it renders is indistinguishable from insatiable — and the
    discriminator is one command, not a human.
18. **an unreadable review is a malfunction I own.** `constraint ✋` at 87% context is an overflow
    whose repair is a scoped re-run. treated as a sealed gate for nine iterations, it hid four
    blockers the whole time. *a verdict I cannot read is a verdict I have not sought hard enough.*
19. **escalation is the last resort, and it is the THIRD rung.** the ladder is: converge → spend every
    driver lever → then a human. **the record of what was tried is what makes an escalation legible.**
20. **a promise in a comment is graded by no runner.** the test file header listed the broken-chain
    report among the renders it covered. it did not cover it, for three rounds.
21. **coverage by recall does not scale past a family of about ten.** the durable repair is not
    diligence but **structure** — `ContractPaths` and the message family now have shapes a gap shows
    up in, rather than lists to re-walk from memory.
22. **a test that makes residue on purpose owes its own reclaim.** the deliverable's mechanisms are
    each scoped by design — run-scoped, or report-only, or age-bounded — so a fixture outside all
    three is reclaimed by no one for a day.
23. **a guard that refuses is not a route to re-plan around.** the test is never "is this command on
    the banned list" but **"does this produce a result the guard was built to withhold".**
24. **a constant is not a covered value.** eleven snapshots rendered `countDirs` and every one
    rendered `0`, because every fixture was degenerate at that axis. *ask of each field: does ANY
    fixture drive this to a non-trivial value?*
25. **a clamp that can be evaded is a clamp that does not hold**, and the evasion is always in the
    syntax you did not think of. a walk written against the code that exists is as strong as the
    codebase's current style and no stronger.
26. **the fix to an unenforceable rule can itself be unenforceable.** eight comments became one regex,
    and the regex was narrower than the comments were. *when you replace prose with a gate, check the
    gate covers what the prose claimed.*
27. **a guard catches its author.** `case=14`'s mint guard refused `rscale001` at the first `mkdir` —
    the mnemonic run ids were not hex. it exists so an unparseable name cannot reach disk and turn the
    age gate off in silence, and its first real catch was the person who wrote it.
28. **a state with a DIRECTION has two poles, and the uncovered pole is the one further from what you
    last edited.** *ask of any directional state whether both directions are driven.*
29. **a message can be proven CORRECT and never proven RECEIVED**, and no snapshot can tell the two
    apart.
30. **re-verify the review record, not only the code.** a review that trusts the prior review inherits
    its blind spots exactly.
31. **when a review names a CLASS, grep for the class before you repair the instance.** *degenerate
    fixture* was named, written into a `.why`, and closed for one render out of six. the search was
    one line.
32. **a `0/0` is one lane's pass, never "the artifact is clean."** the protection comes from the
    **overlap** between lanes, not from any one of them.
33. **do not edit the artifacts while a round is in flight.** the round is identified by a hash of what
    it reviewed; converge *after* the verdicts land, never mid-round.
34. **the two-pole failure recurs — and two rows of one table can be the same surface.** a mnemonic
    failed at it four times; the next form has to be mechanical.
35. **a guard beats a grep beats a citation.** a review cited 2 bad run ids. a grep of the class would
    have found ~6. a guard at the source found **15**, and it will find the 16th. when a review names
    an *instance*, look for the *invariant* that lets the instance exist, and put the check there.
36. **when a repair closes one member of a pair, the other member is the single most likely open gap in
    the diff — check it in the same breath, not in the next round.** this is the mechanical rule that
    replaced the mnemonic of lessons 28/34, after five failures.
37. **an omission can wear the shape of a decision.** *a convention for deliberate gaps only helps if
    its absence is read as a defect.*
38. **partial disagreement is a real verdict, and it must be argued in halves.** wholesale compliance
    with one nitpick would have made `[case10]` render a population member that cannot exist — a *new*
    fidelity defect, introduced by the fix for a fidelity defect.
39. **a file-wide convention is only a convention if it holds file-wide.** *when a file has grown by
    accretion, the highest-yield review is not of the newest case — it is a census of every case
    against the convention the file claims to keep.*
40. **a fragment assertion proves a span survived; it says not one word about shape.** glyphs, line
    breaks and order are the whole content of "what a human reads", and only a snapshot holds them.
41. **when two independent reviewers make the same "mistake", the artifact is the defect.** *a
    reviewer who misreads an artifact is evidence about the artifact.* ask what made the misread
    available; do not merely prove the misread wrong.
42. **a representation that drops a real character is not "close enough".** an absent newline looked
    cosmetic for fifteen rounds, then cost two blockers in one.
43. **two grains that render the same emission must be able to agree character for character.** when
    they cannot, a reader has no way to tell which to trust.
44. **a scoped re-run is a permanent obligation, not a one-time repair.** a lane that overflowed once
    will overflow again on a branch that grows each round — and it fails as `constraint`, silently, so
    its silence reads identically to approval. re-scope against the **current** tree every round.
45. **a documented deferral needs its premise audited, not merely its reason.** a gap with a written
    justification stops to be re-examined, so a wrong premise inside a sound reason survives longer
    than a bare gap would.
46. **a real journey tells you things about your own system that a call to one function cannot.**
47. **a fixture that cleans up before the observation observes its own cleanup.**
48. **a note that describes a hazard is not a guard against it.** the repair is a **count**, not a
    convention: 16 snapshot exports, 16 clean delimiters, checkable by anyone.
49. **a fix applied at the site the report quoted is a fix that will return at the next site.** the
    reviewer's own second paragraph usually holds the argument for the wider repair.
50. **check the SCOPE of a scoped re-run, never its verdict.** the check is one file —
    `input.scope.json` — and it is unconditional. *the reviewer answers the question you asked; the
    risk is that you asked about the wrong files.*
51. **an assertion that ties a product to its prose finds the prose defect.** *a deliverable checked
    off in three parts stays wrong in the part nobody re-read.*
52. **the same character misread by three independent lanes is still not a defect — and the pattern
    still earns an answer.** a fact three careful readers got wrong earns a stated provenance and a
    flagged follow-on rather than a fourth dismissal.
53. **mask the volatile part, never the volatile line.** a defense that reads *"accept the new text"*
    puts a human judgment call in the CI path.
54. **`grepsafe --glob` matches the basename only.** a `/` in the glob yields a clean `0 matches`, exit
    0, indistinguishable from genuine absence. scope with `--path` instead.
55. **repeated `--paths-with` flags do not union — the last one wins**, and a comma-separated form
    reads as one literal glob. use a single glob that covers every target.
56. **a decline can be right about the product and wrong about the record.** *a fact four careful
    readers get wrong is a fact the artifact fails to state — and "I already explained it" is not a
    repair.*
57. **a mask is owed only by a value that CHURNS.** an unconditional mask renders a fixture literal as
    `<run>` and costs a reader real signal.
58. **a readiness probe must watch for its subject's own words.** a fixed sleep races an async report;
    a bare "any stderr" probe fires on whatever speaks first. and an **expired** timer must throw as a
    fixture failure, since truncated stderr reads as a product defect.
59. **a coverage claim in prose is a claim no gate grades.** the most consequential instance: the prose
    was not a description of coverage, it was the argument that justified its removal.
60. **measure a guarantee with the instrument the guarantee is stated in.** this behavior promises a
    **delta** (a run adds no entry), never an **absolute** (the dir is empty). *an absolute count
    cannot distinguish the bug from the mechanism built to catch it.*
61. **check the instrument before you trust what it measured.** twenty-one rounds of snapshot review
    ran on a runner that could not fail, and the only reason it surfaced is a dogfood of a nitpick fix
    that did not seem to need one.
62. **a shell gate that is correct by accident is a defect that has not bitten yet.** `[ -z $CI ]` and
    `[ -z $THOROUGH ]` land on the right answer through the one-argument rule rather than the test they
    appear to run.
63. **a clamp's FIRST render is the cheapest place to learn its promise does not hold.** a "preserved
    order" that jest sorted, and a "hermetic" mask that carried the worktree name — both annotated
    confidently, both false, and in each case the export said so on the first run.
64. **a rule that grades a family must admit every form the family already uses.** *a family-wide rule
    written from memory grades the author's memory, never the family.*
65. **a repair applied to one member of a family splits the family.** the repair is a family-wide
    count, never the one line.
66. **decline a remedy, never a concern.** take the concern as a checked promise; decline the remedy
    *with the reason recorded where the next reviewer will read it.*
67. **a numeric surface a parser must interpret will be misread in both directions.** *diagnose the
    tally before you answer it* — and never answer a point the reviewer did not make.
68. **an answer filed where the reader is not is an answer that gets re-filed.** *an unanswered nitpick
    is re-filed forever* — and so is a mis-filed one.
69. **a `constraint` that hides a blocker hides whatever that blocker's repair would have found.** the
    `--updateSnapshot` defect — the sharpest of the whole stone — sat two steps downstream of a
    **nitpick** in a lane that rendered no verdict at all.
70. **`--goal representative` is the default, and a clean verdict under it is a sample, not a
    verdict.** four lanes read `0/0` under it; the same rubrics under `exhaustive` held 2 blockers and
    5 nitpicks. *check the flag a verdict was produced under before you record it.*
71. **`--paths-with` alone silently drops the `--diffs since-main` default**, and `intersect` against
    an empty diff set resolves to **zero files** — a scope that grades no file at all and reports
    `all clear`. pass `--diffs` explicitly beside it, then read `input.scope.debug.json`.
72. **an answer must be filed in the artifact the reader opens.** for a snapshot reviewer the durable
    place is the **test name**, because the name is the snapshot key.
73. **a citation of someone else's rescope is not a rescope of your own.**
74. **a reviewer's overflow is diagnosable from the log it already wrote.** every overflow prints a
    hint at `tokens.expected.md` — a size-ranked tree of the subject. eight overflows were called
    structural without it once opened; when it was opened, a **quarter** of the subject turned out to
    be a process artifact the repo's own convention already said should not be tracked.
75. **a yield that logs its own iterations is a yield that must be re-read to be understood.**
    `rule.forbid.chronological-accretion`: state current truth, let git hold the history. an
    iteration log is also *pure cost* to every downstream reviewer, since each round's subject
    carries every prior round's narrative.
76. **a rationale written ahead of the render is a guess wearing a rationale.** a new snapshot's
    comment claimed *"every field here is a count, a boolean, or an empty list — deterministic by
    construction"*, and its very first render carried a live run id. the claim was authored before
    the record existed. **this is the third instance of one shape on this branch** — twice a mask
    leaked a home dir or a checkout name, once a `.note` asserted a walk-up the export did not do.
    *the fix is order, never care: read the render, then write why it is safe.*
77. **a reviewer's "fix" that quotes your own code back to you is a false positive with a tell.**
    one blocker cited a file that holds neither the case nor the symbol it named, and its proposed
    snippet was the extant code verbatim, comment and all. *before a repair, confirm the cited
    location exists* — the cheapest check is a grep for the symbol in the file named.
78. **a subset clamp must name its own remainder, or it reads as an oversight forever.** an exports
    shape snapshot graded three of six subpaths and said no word about the other three, so a reader
    could not tell a bound from a gap — and a seventh subpath would have joined neither. the repair
    is not a comment: **derive the remainder from the source of truth and carry it in the record**,
    so the next addition reddens the snapshot and the next author meets the question.
79. **one concept masked by two tokens reads as drift to whoever diffs the two files.** the same
    broken-chain report rendered `node: <node>` at one grain and `node: <version>` at another. the
    LABEL already names which version it is, so the token owes only *a version* — and when a token
    changes, its paired guard-the-guard must read the **label** with it, or the assertion survives a

## r7's nitpick was a FALSE POSITIVE, and its cause is reproducible

r7 reported a **mixed** glyph state: 🧹 in one snapshot file, 🐢 in the other two. measured:

> **lesson 137 — a reviewer's prompt holds its subject AND the transcript of every prior round, and

## r8's two nitpicks were HELD, and both got the exemption r8 itself offered

both ask to mask a literal. both refused for one reason — **the literal IS the assertion** — and one
premise was wrong:

> *"on a machine where that path exists it would render a stranger's real directory."*

it cannot. `/non/existent/fixture/path` is the value **the test hands in**
(`genTempDir.acceptance:360`), so the render echoes it back on every machine, forever. were the path
to exist, the test would fail because no error is thrown — never by a leaked name.

the general rule is now written at **both** sites, in the source rather than only in a `.taken`:

> **mask what the CODE chose; never mask what the TEST chose.**

that also settles the `to`/`from` pair r8 read as inconsistent: `to` is a fresh temp dir the code
picks per run (masked), `from` is a fixed literal the test picked (not masked). same rule, opposite
sides.
