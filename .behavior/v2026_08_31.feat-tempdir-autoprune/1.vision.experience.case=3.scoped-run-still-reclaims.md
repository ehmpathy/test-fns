# case=3 — the scoped run still reclaims

> cell 3 · `hooks=jest|vitest` · `termination=scoped` · `solo` · `reclaim`
> **feel** happy · **care** critipath — a named prior incident, twice paid for

## the narrative

kai touches one file and runs only what it affects:

```
$ rhx git.repo.test --what unit --scope 'path://genTempDir' --mode apply
```

that is the **inner** loop — the one kai runs forty times a day, far more often than a full
suite. it allocates fewer dirs per run, and runs so many times that it out-leaks the full suite
by a wide margin.

this cell exists because of a specific, documented failure, quoted in the wish:

> a per-case sweep read its dir list **as of the moment it ran**, so dirs registered later
> survived every run — and under `--scope` its whole subject set went unswept with no verdict
> rendered at all.
>
> the cure was structural rather than a sharper check.

**1,786 orphan dirs accrued under a green clamp.** the clamp was green because the clamp itself
sat in the unswept subject set. that is the trap: a scoped run can silently exclude the very test
that would have caught the exclusion.

## why this design cannot repeat it

the prior defect had two ingredients. this design removes both:

| ingredient of the defect | what removes it |
|---|---|
| the sweep ran **per case**, so it read a list frozen mid-run | the reclaim runs **once**, in the global teardown, after every file |
| the sweep's subject set was **selected by scope**, so scope could exclude it | the global teardown is **config**, not a test — no scope selector can deselect it |

the second removal carries the load. a teardown that is a *test* can be filtered out by a test
filter. a teardown that is a *runner hook* cannot — the runner calls it whether it ran one test
or ten thousand.

## the timeline

```gherkin
given('[case3] an enhooked repo, run with a scope that selects one test file of many', () => {

  // ⚠️ the cast, declared up front — every demo owes this. an assignment
  //    inside a `then` whose body holds no assertion at all breaks
  //    rule.forbid.failhide, and leaves `pathPhysical`, `report` and
  //    `allSuites` as free variables.
  const { pathPhysical } = getOneTempDirRoot();
  const countBefore = useThen('the contained dir holds a prior count', () =>
    countTempDirs(pathPhysical),
  );
  const allSuites = useThen('the repo has many test suites', () => countAllSuites());
  const RScoped = useThen('a scoped run starts — one file of many', () =>
    mintRun({ scope: 'path://genTempDir' }),
  );

  when('[t0] the run has not yet begun', () => {
    then('the prior count is a real measurement', () => {
      expect(countBefore).toBeGreaterThanOrEqual(0);
      expect(allSuites).toBeGreaterThan(1);
    });
  });

  when('[t1] the run executes only the selected subset', () => {
    const report = useThen('the runner reports what it ran', () => reportOf(RScoped));

    then('the unselected files did not run', () => {
      expect(report.numTotalTestSuites).toBeLessThan(allSuites);
    });

    then('the selected file allocated its fixtures', () => {
      expect(countTempDirs(pathPhysical, { run: RScoped })).toBeGreaterThan(0);
    });
  });

  when('[t2] the global teardown runs', () => {
    then('the scoped run reclaimed exactly its own', () => {
      // 📏 the whole-dir equality is placed SECOND, as a consequence of the
      //    run-scoped fact above it — never a standalone claim over a shared
      //    namespace (case=5 [t3]'s discipline). cases 1, 2 and 3 all carry
      //    this order.
      expect(countTempDirs(pathPhysical, { run: RScoped })).toEqual(0);
      expect(countTempDirs(pathPhysical)).toEqual(countBefore);
    });
  });

  when('[t3] the scope is narrowed to select ZERO test files', () => {
    const RZero = useThen('a run whose scope selects no file starts', () =>
      mintRun({ scope: 'path://no-such-file' }),
    );

    then('the teardown still runs and still renders a verdict', () => {
      // the precedent's exact failure: a scope that deselects the sweep itself
      expect(exitCodeOf(RZero)).toEqual(0);
      expect(countTempDirs(pathPhysical, { run: RZero })).toEqual(0);
      expect(countTempDirs(pathPhysical)).toEqual(countBefore);
    });
  });
});
```

## `[t3]` is the clamp that bites

a scope that matches **zero** files is the degenerate case that reproduces the incident. under the
old shape it was a silent no-op with no verdict. under this shape the runner still calls its
global teardown, so the guarantee still holds and still reports.

a reviewer should insist `[t3]` exists. without it, `[t2]` alone would pass under the very design
that produced 1,786 orphans.
