# case=4 — the interrupted run falls to the age gate

> cell 4 · `hooks=jest|vitest` · `termination=interrupt` · `solo` · `reclaim`
> **feel** ⚡ **sharp** · **care** critipath — the teardown never runs; it needs a backstop

## the narrative

kai's suite hangs on a deadlocked fixture. kai hits `ctrl-c`. it does not die, so kai reaches for
`kill -9`.

the process is gone. no teardown ran. **thirty fixture dirs are on disk, and no code executed to
claim them.** this is the one cell the run-scoped reclaim structurally cannot reach — not a bug in
it, a boundary of it.

so the sharp edge is real and permanent. the question is not *how do we prevent it* but **what
catches it, and how loudly does the design admit it cannot.**

## how it fails safe

three properties, in order:

1. **it fails toward leak, never toward loss.** an interrupted run's dirs survive. that is the
   correct bias — a stranded fixture costs disk; a wrongly-reaped one costs a human's work.
2. **the dirs carry a dead run id.** no later run claims them, because no later run shares that
   id. so the leak cannot cascade into a wrong reap
   ([case=5](./1.vision.experience.case=5.peer-parallel-run-is-untouched.md) depends on this).
3. **the age gate is the backstop, and it must stay.** the extant `pruneStale`
   (`src/domain.operations/genTempDir/pruneStale.ts`) already reclaims by dir-name timestamp. this
   cell is **half of its remaining job** — the other half is the hatch
   ([case=6](./1.vision.experience.case=6.hold-keeps-them-and-says-where.md)).

**this is the load-bearing reason the age gate is not deleted by this behavior.** a reviewer who
sees the run-scoped reclaim land and asks "so we can drop `pruneStale` now?" must be pointed here.
the gate changes role — from *primary reclaim* to *backstop* — and its default window becomes a
tuned choice rather than a long tail (#66, out of scope for this tree).

## what it must NOT do

a design that tried to close this cell would reach for a liveness probe: *scan the contained dir,
reap any entry whose owner pid is dead.* that is the shape this behavior refuses.

- a pid is reused, so "dead pid" is not a sound claim
- a pid carries no sense across a container boundary or a reboot
- it is the `find -mtime +3` shape the wish names — it **guesses** at abandonment rather than
  verifies it, and its blast radius is a peer's live fixtures

the honest posture: **name the boundary, leave the residue, let the gate take it.** the residue is
bounded by the gate window, and bounded is the whole win.

## the timeline

```gherkin
given('[case4] an enhooked run that allocated fixtures, then died before its teardown', () => {

  // ⚠️ the cast is declared up front, on the same discipline case=11 keeps.
  //    R, R2 and N are bound here, never read as free variables below.
  const { pathPhysical } = getOneTempDirRoot();
  const R  = useThen('a full run starts and mints an id', () => mintRun());
  const N  = useThen('it allocates its fixture dirs', () =>
    countTempDirs(pathPhysical, { run: R }),
  );
  const R2 = useThen('a LATER run starts, under its own id', () => mintRun());

  when('[t0] the run allocated N dirs under run id R', () => {
    then('the dirs exist and carry R', () => {
      expect(countTempDirs(pathPhysical, { run: R })).toEqual(N);
      expect(N).toBeGreaterThan(0);
    });
  });

  when('[t1] the run is killed with SIGKILL', () => {
    then('the teardown did not run', () => {
      expect(countTempDirs(pathPhysical, { run: R })).toEqual(N);
    });

    then('the residue survives — the safe direction', () => {
      // fails toward leak, never toward loss
      expect(countTempDirs(pathPhysical, { run: R })).toBeGreaterThan(0);
    });
  });

  when('[t2] a LATER run starts in the same repo, under a new run id R2', () => {
    then('the later run does NOT claim the dead run\'s dirs', () => {
      expect(countTempDirs(pathPhysical, { run: R })).toEqual(N);
    });

    then('the later run reclaims only its own', () => {
      expect(countTempDirs(pathPhysical, { run: R2 })).toEqual(0);
    });
  });

  when('[t3] the age gate window elapses and any later run calls genTempDir', () => {
    then('the stranded dirs are reclaimed by age, not by guesswork', () => {
      expect(countTempDirs(pathPhysical, { run: R })).toEqual(0);
    });
  });

  // 🔴 cell 3c — `scoped × interrupt`, and it is a SEPARATE cell, not a rerun.
  // collapse 5 keeps 3c distinct because its residue is a SCOPED SUBSET whose
  // id no later run claims — the exact `1,786 orphan` shape. [t0]–[t3] above
  // are all FULL runs, so not one of them exercises that half.
  // a grade of "demoed by subsumption via case=4" that points at a timeline
  // with no scope in it is an unproven subsumption — the same defect cell 3b
  // carries without case=12 [t6]. so 3c gets a real scoped step of its own.
  when('[t4] a SCOPED run is interrupted — `--changedSince=main`, then ctrl-c', () => {
    const R3 = useThen('a scoped run starts and mints an id', () => mintScopedRun());
    const dirsMadeByR3 = useThen('it makes fixture dirs for its SUBSET only', () =>
      countTempDirs(pathPhysical, { run: R3 }),
    );

    then('the subset is genuinely smaller than the full run\'s', () => {
      // without this the step is a full run under a scoped label
      expect(dirsMadeByR3).toBeGreaterThan(0);
      expect(dirsMadeByR3).toBeLessThan(N);
    });

    then('SIGKILL strands them, exactly as it stranded the full run\'s', () => {
      expect(countTempDirs(pathPhysical, { run: R3 })).toEqual(dirsMadeByR3);
    });

    then('and NO later run claims them — the 1,786-orphan shape, refused', () => {
      // the scoped residue carries R3. a later run matches its own id only,
      // so the subset is never adopted by a run that did not make it.
      expect(countTempDirs(pathPhysical, { run: R3 })).toEqual(dirsMadeByR3);
    });

    then('the gate takes them by AGE, on the same terms as the full run\'s', () => {
      // ⚠️ the point of the cell: coverage does not reach the reclaim at all.
      // the gate reads a dirent's mtime; it has no notion of which tests ran.
      expect(countTempDirs(pathPhysical, { run: R3 })).toEqual(0);
    });
  });
});
```

## 🔴 `[t4]` carries cell 3c

collapse 5 keeps `scoped × interrupt` as its **own** cell (**3c**), on the ground that its residue
is a **scoped subset whose id no later run claims** — the exact `1,786 orphan` shape this whole
behavior descends from. 3c is graded **`demoed by subsumption · critipath`** and the subsumption
points at this file — whose `[t0]`–`[t3]` run **no scope at all**. `[t4]` is what makes that grade
true.

without `[t4]` the cell is simultaneously:

- **distinct enough not to collapse** (collapse 5 says so), and
- **covered by a demo of the very cell it was declared distinct from**

cell 3b carries the same debt, and pays it with `case=12` `[t6]` — a step that genuinely runs
`--changedSince=main --forceExit`. *subsumption is a claim about coverage, and a claim about
coverage is only as good as the timeline that carries it.*

> **the shape, and it is worth more than any one repair:** a **regrade is not a free action.** to
> move a cell from `itemized` to `demoed by subsumption` is to make a **new coverage claim**, and a
> new claim owes the same evidence as an original one. a regrade treated as a correction to a label
> never asks the question the label commits to — *does the cited timeline exercise the half that
> makes this cell distinct?*

`[t4]`'s second `then` is the one that keeps it honest: **the subset must be measurably smaller than
the full run's**. without it the step is a full run under a scoped label, and the demo would pass
while it proved no part of the claim — the green-and-blind shape `case=8` forbids.

## `[t2]` is the one a reviewer must not let slide

it looks like a redundant restatement of `[t1]`. it is not. it is the assertion that the **leak
does not become a loss** — that the natural "clean up the old stuff" instinct was not coded in.
if `[t2]` were absent, a later maintainer could add a well-meant sweep of aged-out-of-this-run
dirs and turn this benign cell into
[case=5](./1.vision.experience.case=5.peer-parallel-run-is-untouched.md)'s data loss.

## the honest cost, stated

between the kill and the gate window, the dirs sit on disk. this vision shortens the window from
the extant 7 days to **24 hours**, which cuts the tail by 7× — and it can, because the marker now
carries `pid` + `startedAt`, so *"is this residue's owner still alive?"* is a question with an
answer rather than a margin. **the cell still leaks by design, and the design says so out loud
rather than pretend otherwise.**
