# 1.vision.experience.case=_ — the inventory

## .what

the walked product from `1.vision.experience.dimensions.md`, every cell verdicted, each real
experience given a **feel** (happy · sharp) and a **care** (critipath · alterpath, `freq × cost`).

this is the **coverage contract**. a critipath here owes a `case=N` demo. per
`rule.require.experience-catalog-evolution`, a critipath discovered at any later stage is added
here **before that stage passes**.

## .the legend

| verdict | sense |
|---|---|
| **demoed** | a real experience, demonstrated in a `case=N` |
| **itemized** | a real experience, on record, deliberately not demoed |
| **forbidden** | attemptable, and the behavior must **reject** it — an invariant |
| **impossible** | no attempt is possible by nature — void |

**the set is closed at four, and the column asks exactly one question: _how well does this walk
cover this cell?_** the first two are coverage grades over a real experience; the last two are the
two ways a cell can fail to be an experience at all.

> 🔴 **a fifth verdict does not belong here, and the reason is the most instructive item in this
> legend.**
>
> the diagnosis that reaches for one is usually right about what it noticed: cell 13 is graded over
> a demo that asserts `exit 0`, and *"the behavior must reject it"* is plainly not what `case=6`
> `[t2]` shows — it warns loudly and proceeds. one word was made to carry two different contracts.
>
> **but a second word is the wrong repair.** *refuse* and *tolerate and say so* are indeed different
> promises — and they are both answers to **"what does the behavior do?"**, while this column asks
> **"how well is this cell covered?"** cell 13 has a demo. its verdict is **demoed**; the
> loud-and-tolerant contract is what that demo *shows*, and it belongs in the note beside the cell,
> where it is.
>
> > **when a label does not fit, ask what question the column asks before you invent a word that
> > fits the label.** a value that answers a different question is not an absent verdict — it is
> > content in the wrong column.
>
> `impossible` holds **zero** cells today. it stays in the legend because the grid may reach one, and
> because a verdict set that shrinks to what a walk happens to use is no longer a check on that walk.
>
> 🔴 **`forbidden` held zero for five rounds, and now holds two** — cells **16b** and **17b**, the
> two adopter attempts the contract refuses. it was kept at zero on exactly the argument above, and
> the argument paid: the row stayed on the page as an open question, and a later walk answered it.
> see region 4's note for what the walk had been mistaking for a domain-wide fact.

half**; neither has its own file, because neither adds a mechanism.

**3b also changes the priority of A6's probe** — an assumption that seemed an edge is the common
path — so it is carried into the register as well as into this table.

**cells 8b/8c hold the runs whose teardown never fired** — a CI hard timeout, a human's `^C`, an OOM
kill, a `globalSetup` throw. the reclaim never runs, so a `globalTeardown`-based guard is
structurally blind to it and an out-of-band detector is the only reach.

**8b earns its own case, and the reason is worth a record.** the weaker treatment is *"demoed by
extension"* of case=1 — a clean run, under one added flag — with the gap tracked as the assumption
`A6` plus an owed clamp. graded against the guide's fail-safe triad (**fast · loud · teaches the
fix**), 8b is the one row with **no fail-safe at all**: `case=10`'s invariant lives *inside* the
teardown, so it is structurally blind to a teardown that never runs. an owed clamp protects **us**
on today's jest; it protects no consumer on tomorrow's.
[case=12](./1.vision.experience.case=12.teardown-never-ran-next-run-says-so.md)
supplies the fail-safe — an arrears check in the **next** run's setup — which also hands cell 4 the
loud leg it lacked.

**why 6–8 and 8c are critipath, yet demoed by one case.** the easy grade for all four is
**alterpath**, on the argument that peer-safety is a property of the **name** rather than a runtime
check, so it does not vary with termination mode. **that is a coverage argument used to settle a
care question** — precisely the conflation `define.experience._.metric=boundary-density` forbids:

> *care sets the severity (blocker vs nitpick if absent); density sets the priority and scrutiny
> … do not conflate them.*

run separately, the two judgments both land, and they land differently:

- **care** — a wrong reap here destroys a **live peer's** fixtures. there is no workable fallback:
  the work is gone, and the peer's run fails in a way that looks like its own defect. that is a
  **critipath** under every termination value, because the cost does not fall when the run ends
  differently.
- **coverage** — [case=5](./1.vision.experience.case=5.peer-parallel-run-is-untouched.md) already
  walks this cell's whole boundary set. 6–8 and 8c vary an axis the peer-safety property does not
  read, so a separate case per row would restate case=5 four times — `rule.forbid.rambles` in
  artifact form.

so: **critipath by care, demoed by subsumption for coverage.** the care verdict is what makes the
row set a blocker if case=5 ever goes absent; the coverage verdict is what keeps the artifact set
from a fourfold restatement with no new boundary.

⚠️ **the caveat that survives.** subsumption holds *only while peer-safety is a property of the
name*. if execution makes it a **runtime check** instead, the property becomes readable by
termination mode — a check can be pre-empted by a forced exit, raced by an interrupt — and these
four rows each earn their own demo.

>

> ⚠️ **this block was a PARAPHRASE that claimed to be a transcript.** it said *"renders exactly, and

> agreement (`run(s) … their` where the shipped render agrees `run … its`), the `run:` colon, the

> note asked for, and the `errno`-prefixed residue lines are what send the reader to **the
> filesystem** rather than to the wire-up. the test's own `then` names that intent verbatim.
>
> **the lesson:** *"the mechanism is a composition of demoed parents"* settles that a cell needs no
> new **guard**. it does **not** settle that the cell needs no demo — because what cell 25 owed was
> never a mechanism, it was a **message**, and a message is exactly the kind of output a demo pins.
> **when a cell's whole obligation is a distinct human-faced output, `itemized` cannot discharge
> it.**

> 🔴 **`unremovable × interrupt` does NOT fold into cell 25.** the fold's claim — *"a SIGKILL
> mid-report has the identical outcome … the discrimination that fixes one fixes both"* — is false.
> the two are settled **differently**, by the very state machine cell 25 introduced:
>
> | | `unremovable × preempted` (cell 25) | `unremovable × interrupt` (cell 4) |
> |---|---|---|
> | the teardown | **begins**, meets the stuck dir, is torn down mid-report | **never begins** |
> | the marker settles to | **`partial`** | **`open`** |
> | the arrears message | *"a dir would not delete"* + path + `errno` | *"a prior run was interrupted"* |
> | the dir's removability | **tested**, and it failed | **never tested** |
>
> under `interrupt` the reclaim never runs, so the dir's un-removability is **never discovered** —
> it is residue like any other, and cell 4 already owns it. `dimensions.md`'s collapse 6 has this
> right, and a section that contradicts it leaves a reader who meets both unable to tell which
> holds.
>
> **the lesson:** cell 25 exists *because* `partial` distinguishes a teardown that began from one
> that did not. to then fold a never-began case into it **erases the distinction the cell was
> created to draw** — such a fold is not merely wrong, it undoes its own cell's reason to exist.

## boundary density — what to center

ranked by `rule.require.experience-coverage`'s density metric:

1. **case=11 (the friday afternoon)** — **9 boundaries in one walk**, and the only demo of their
   interaction. by the density brief this is both the highest-value and the highest-risk demo, so
   it earns the deepest scrutiny. it is the one to center.

   ⚠️ **a stale composite is worse than an absent one** — it advertises breadth it no longer has,
   and a reviewer who trusts the rank scrutinizes the wrong artifact. every case added after the
   composite is written adds a boundary the composite does not yet walk, so the rank drifts
   silently. the walk carries class **E** (dirs the gate cannot read), a pre-empted run, and the
   arrears check that must name a dead run **while a live peer's marker is equally uncleared**.
   **whoever adds the next case owes this composite a re-walk.**
2. **cells 19, 8b, and 21 (the three silent cells)** — the set that fails **silently under a green
   suite**, the precise failure mode the wish exists to end. each has a different cause and each
   needs its **own** guard, at its own layer, because no one of them can see another's cause:

   | cell | cause | guard | where it lives |
   |---|---|---|---|
   | 19 ([case=10](./1.vision.experience.case=10.broken-mint-chain-is-caught.md)) | the teardown runs, matches zero | `orphan exists ∧ matched==0` | the teardown |
   | 8b ([case=12](./1.vision.experience.case=12.teardown-never-ran-next-run-says-so.md)) | the teardown never runs | an uncleared run marker | the **next** run's setup |
   | 21 ([case=14](./1.vision.experience.case=14.the-stamp-must-not-break-the-age-gate.md)) | the name is unreadable to the age gate | the name parses back | the **mint** |

   a reviewer must confirm **all three** survive execution. any one alone leaves the others' half
   of the silence wide open — and cell 21's is the worst, because it removes the age-gate floor
   that cells 4, 8b, 13, and 8c all stand on.
3. **cell 5 (peer-parallel)** — the only cell where a defect **destroys a human's live work**
   rather than merely leaks. highest cost, non-zero frequency.
4. **cells 14/15 (unhooked)** — the only cell whose default value is "broken", and it is the
   default for *every consumer* on release day.
5. **cell 3 (scoped)** — the cell with a **named prior incident** (1,786 orphans under a green
   clamp). we have already paid for this one twice.

the guardrail from the density brief is respected: `case=11` supplies **breadth**; cases 4, 6, 9,
and 10 keep their **focused spotlights** so each sharp critipath's fail-safe stays legible.
