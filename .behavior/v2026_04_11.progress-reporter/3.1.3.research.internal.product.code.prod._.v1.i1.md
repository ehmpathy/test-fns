## pattern.1 = jest reporter implementation

**source:** `src/domain.operations/slowtestReporter/reporter/SlowtestReporterJest.ts`

**classification:** [REUSE]

**why:** the progress reporter follows the same jest reporter pattern. we implement the same Reporter interface with the same lifecycle hooks.

### citations

**[1]** reporter class structure (lines 32-36):
```ts
export class SlowtestReporterJest implements Reporter {
  private config: SlowtestConfig;
  private files: SlowtestFileData[] = [];
  private thresholdMs: number;
```

**[2]** constructor receives global config and options (lines 37-42):
```ts
constructor(_globalConfig: Config.GlobalConfig, options?: SlowtestConfig) {
  this.config = options ?? {};
  this.thresholdMs = this.config.slow
    ? parseThresholdToMs({ threshold: this.config.slow })
    : getDefaultThreshold({ scope: 'unit' });
}
```

**[3]** onRunStart hook (lines 48-53):
```ts
onRunStart(
  _results: AggregatedResult,
  _options: ReporterOnStartOptions,
): void {
  // no-op: we collect data at test execution time
}
```

**[4]** onTestFileResult hook to collect data (lines 59-93):
```ts
onTestFileResult(
  _test: Test,
  testResult: TestResult,
  _aggregatedResult: AggregatedResult,
): void {
  // extract file path relative to cwd
  const filePath = testResult.testFilePath.replace(process.cwd() + '/', '');

  // compute file duration from perfStats
  const fileDuration = testResult.perfStats.end - testResult.perfStats.start;
```

**[5]** onRunComplete hook for final output (lines 115-147):
```ts
async onRunComplete(
  _testContexts: Set<TestContext>,
  results: AggregatedResult,
): Promise<void> {
  // compute total duration
  const totalDuration = results.startTime
    ? Date.now() - results.startTime
    : this.files.reduce((sum, f) => sum + f.duration, 0);
```

**[6]** default export required by jest (lines 158-159):
```ts
// biome-ignore lint/style/noDefaultExport: jest reporter api requires default export for custom reporters
export default SlowtestReporterJest;
```

### applicability to progress reporter

- implement same Reporter interface
- use onRunStart to initialize interval timer
- use onTestFileResult to update counts and capture failures
- use onRunComplete to clear timer and emit summary
- use default export pattern

## pattern.3 = config interface

**source:** `src/domain.objects/SlowtestConfig.ts`

**classification:** [REUSE]

**why:** the progress reporter needs a similar config interface for the `dir` option.

### citations

**[8]** config interface with optional fields (lines 5-42):
```ts
export interface SlowtestConfig {
  /**
   * slow threshold in ms or human-readable string (e.g., "3s", "500ms")
   *
   * note
   * - when string, parsed via iso-time to milliseconds
   * - default: 3000ms for unit tests, 10000ms for integration/acceptance
   */
  slow?: number | string;

  /**
   * output json path (e.g., ".slowtest/report.json")
   *
   * note
   * - if not set, json output is skipped
   * - directory created if absent
   */
  output?: string;
```

### applicability to progress reporter

- create `ProgressConfig` interface with `dir` option
- make `dir` required (per vision: require explicit path)
- add clear JSDoc documentation

## pattern.5 = iso-time duration utilities

**source:** `iso-time` package (dependency at 1.11.3)

**classification:** [REUSE]

**why:** the vision specifies ISO 8601 duration format (`PT2M34S`). iso-time provides this.

### citations from package docs

**[12]** getDuration to compute elapsed time:
```ts
import { getDuration } from 'iso-time';

const elapsed = getDuration({
  of: { range: { since: '2024-06-15T10:00:00Z', until: '2024-06-15T12:30:00Z' } },
}); // { hours: 2, minutes: 30 }
```

**[13]** duration type for ISO 8601 words format:
```ts
import type { IsoDurationWords } from 'iso-time';

const cacheTtl: IsoDurationWords = 'PT5M';           // 5 minutes
const sessionTimeout: IsoDurationWords = 'PT30M';   // 30 minutes
```

**[14]** stopwatch pattern to track elapsed time:
```ts
import { startDurationStopwatch } from 'iso-time';

const stopwatch = startDurationStopwatch({ for: 'api call' }, { log: console });
await fetchData();
const { duration } = stopwatch.stop(); // logs elapsed time
```

### applicability to progress reporter

- use startDurationStopwatch in onRunStart
- stop and get duration in heartbeat emission
- convert duration to IsoDurationWords format for output
- stopwatch tracks elapsed time automatically
