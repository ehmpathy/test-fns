# blackbox criteria matrix: progress reporter

## matrix.1 = overview heartbeat outputs

| ind: test state | ind: time in run | dep: heartbeat emitted | dep: counts consistent | dep: duration format |
|-----------------|------------------|------------------------|------------------------|----------------------|
| mid-run | every ~1s | yes | remains + passed + failed + skipped = outof | ISO 8601 (PT2M34S) |
| complete | final heartbeat | yes | remains = 0, passed + failed + skipped = outof | ISO 8601 (PT2M34S) |
| crashed | process terminated | last before crash preserved | partial state | ISO 8601 (PT2M34S) |

## matrix.2 = failure capture outputs

| ind: test outcome | ind: console output size | dep: in failures.jsonl | dep: stdout | dep: stderr | dep: failure |
|-------------------|--------------------------|------------------------|-------------|-------------|--------------|
| passed | any | no entry | n/a | n/a | n/a |
| skipped | any | no entry | n/a | n/a | n/a |
| failed | small (<10kb) | yes | full console.log | full console.warn/error | full assertion + stack |
| failed | large (>10kb) | yes | truncated to 10kb | truncated to 10kb | full (no truncation) |
| failed, no output | none | yes | empty | empty | assertion + stack |

## matrix.3 = console output separation

| ind: console method | dep: target field |
|---------------------|-------------------|
| console.log | stdout |
| console.warn | stderr |
| console.error | stderr |
| assertion error | failure |
| stack trace | failure |

## matrix.4 = directory and file creation

| ind: dir exists | ind: files exist | dep: dir created | dep: overview append | dep: failures append | dep: summary |
|-----------------|------------------|------------------|----------------------|----------------------|--------------|
| no | n/a | yes | new file | new file | new file |
| yes | no | no | new file | new file | new file |
| yes | yes (prior run) | no | append | append | overwrite |

## matrix.5 = test count states

| ind: passed | ind: failed | ind: skipped | dep: remains | dep: invariant |
|-------------|-------------|--------------|--------------|----------------|
| 0 | 0 | 0 | outof | remains = outof |
| some | 0 | 0 | outof - passed | holds |
| some | some | 0 | outof - passed - failed | holds |
| some | some | some | outof - passed - failed - skipped | holds |
| 0 | 0 | all | 0 | skipped = outof |

## matrix.6 = reporter configuration

| ind: dir option | dep: reporter behavior | dep: files written |
|-----------------|------------------------|---------------------|
| provided, valid | normal operation | all three files to dir |
| provided, nested path | creates full tree | all three files to dir |
| absent | throws error | none |

## matrix.7 = summary outputs

| ind: run outcome | dep: summary.json written | dep: summary content |
|------------------|---------------------------|----------------------|
| complete, all pass | yes | passed, failed=0, skipped, outof, duration |
| complete, some fail | yes | passed, failed, skipped, outof, duration |
| complete, all skip | yes | passed=0, failed=0, skipped=outof, duration |
| crash mid-run | no (process died) | n/a |

## matrix.8 = parallel execution

| ind: worker count | dep: counts aggregated | dep: failures captured | dep: file write safety |
|-------------------|------------------------|------------------------|------------------------|
