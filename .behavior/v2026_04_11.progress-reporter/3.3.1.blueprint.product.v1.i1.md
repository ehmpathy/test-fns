# blueprint: progress reporter

## summary

build a jest reporter that emits real-time test progress to files:
- `progress.overview.jsonl` — heartbeat every ~1s with counts and duration
- `progress.failures.jsonl` — one line per failure with path, suite, failure, stdout, stderr
- `progress.summary.json` — final state at run completion

### domain.operations/progressReporter/reporter/ProgressReporterJest

```
ProgressReporterJest implements Reporter
├── private state
│   ├── [+] config: ProgressConfig
│   ├── [+] passed: number
│   ├── [+] failed: number
│   ├── [+] skipped: number
│   ├── [+] outof: number
│   ├── [+] failures: ProgressFailureLine[]
│   ├── [+] heartbeatInterval: NodeJS.Timeout | null
│   └── [+] startTime: number
│
├── [+] constructor(_globalConfig, options?)
│   ├── validate dir is provided
│   ├── create directory if absent
│   └── initialize state
│
├── [+] onRunStart(_results, options)
│   ├── initialize outof = 0 (updated in onTestFileResult)
│   ├── set startTime
│   ├── start heartbeat interval (1000ms)
│   └── emit initial overview line
│
├── [+] onTestFileResult(_test, testResult, aggregatedResult)
│   ├── update passed/failed/skipped counts from testResult.testResults
│   ├── update outof from aggregatedResult.numTotalTests
│   ├── for each failed test:
│   │   ├── build failure line
│   │   ├── separate console.log → stdout, console.warn/error → stderr
│   │   ├── truncate stdout/stderr to 10kb
│   │   └── append to failures.jsonl
│   └── emit heartbeat (in case interval hasn't fired)
│
├── [+] onRunComplete(_testContexts, results)
│   ├── clear heartbeat interval
│   ├── emit final overview line
│   └── emit summary.json
│
├── [+] emitHeartbeat() [private]
│   ├── compute duration via iso-time
│   ├── compute remains = outof - passed - failed - skipped
│   └── append overview line to overview.jsonl
│
└── [+] getLastError(): Error | undefined
    └── return undefined
```

### domain.operations/progressReporter/transform/asProgressOverviewLine

```
asProgressOverviewLine
├── [+] input: { passed, failed, skipped, remains, outof, durationMs }
└── [+] output: string (json line)
    ├── format duration as ISO 8601 via asIsoDurationWords
    └── return JSON.stringify({ passed, failed, skipped, remains, outof, duration })
```

### domain.operations/progressReporter/transform/asProgressFailureLine

```
asProgressFailureLine
├── [+] input: { testResult, testCaseResult }
└── [+] output: string (json line)
    ├── path = testResult.testFilePath (relative)
    ├── suite = ancestorTitles.join(' › ') + ' › ' + title
    ├── failure = failureMessages.join('\n')
    ├── stdout = console entries where type='log', truncate to 10kb
    ├── stderr = console entries where type='warn'|'error', truncate to 10kb
    └── return JSON.stringify({ path, suite, failure, stdout, stderr })
```

### domain.operations/progressReporter/transform/asIsoDurationWords

```
asIsoDurationWords
├── [+] input: { milliseconds: number }
└── [+] output: IsoDurationWords (e.g., 'PT2M34S')
    ├── [←] use iso-time getDuration to get shape
    └── [←] use iso-time format to convert to words
```
