# case=10 — a setup that throws once is rescued (B8)

cells: 27 (jest), 28 (vitest), 29 (fail-every) · feel × care: happy × criti

## .narrative

a consumer drives a real reflect inside `given.repeatably({ attempts: 3, criteria: 'SOME' })`, with
the drive in a `useBeforeAll`. on attempt 1 the brain names a file that is absent, and the setup
throws `ENOENT`. today jest fails both `then` blocks of attempt 1 without a call into either. the
wrapper never sees the error, so it marks attempt 1 as passed; attempts 2 and 3 skip their setup and
their asserts. the file is red, and the retry never ran.

after the change `usePrep` knows it sits in a `SOME` attempt. it catches the setup error, marks the
attempt failed, logs `🫧 [withheld] attempt 1 failed, a retry follows: ENOENT`, and returns. the
`then` blocks of attempt 1 read the unset scene, throw, and are withheld. attempt 2 runs the setup
again; this time the brain names a real file; the asserts pass; the file is green.
