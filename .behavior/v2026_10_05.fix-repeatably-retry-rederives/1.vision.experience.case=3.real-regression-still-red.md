# case=3 — a real regression stays red, after a real retry

cells: 3, 21 · feel × care: sharp × criti

## .narrative

a consumer changes the guard's output format. every attempt mismatches. today attempt 1 goes red and
attempts 2 and 3 print skip markers — the retry is a claim, never a fact. after the change each
attempt drives and mismatches; attempts 1 and 2 are withheld; attempt 3 is final, so its mismatch
surfaces with the normal jest diff. the human reads one honest failure, with the diff, after three
honest drives. `-u` settles it as for any snapshot.

a second consumer wraps the same case with `attempts: 1`. there is no retry to wait for: the first
attempt is the final one, so its mismatch surfaces at once, with the diff, and the file goes red. the
wrapper never withholds a failure no later attempt could redeem — that would be a silent green.

## .bdd timeline

  - when `[t0]` attempts 1..N-1 run under `SOME`
    - then each mismatch is withheld; each attempt re-drives (factory count reaches N)
  - when `[t1]` attempt N runs

    - then jest prints the diff against the ordinal-free key
  - when `[t2]` the run summary prints
    - then the tally reads `Snapshots: 1 failed`, not N
    - then jest exits non-zero
  - when `[t3]` the same case runs with `attempts: 1` (cell 21)
    - then attempt 1 is final, so its mismatch surfaces at once, never withheld
    - then the test is red — a withhold here would turn the only failure into a silent green
