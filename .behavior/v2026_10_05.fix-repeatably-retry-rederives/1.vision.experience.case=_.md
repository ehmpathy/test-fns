# 1.vision.experience.case=_

## .what

the inventory of every cell the walk of `1.vision.experience.dimensions.md` leaves, each verdicted.

verdicts: **demoed** (a `case=N` file) · **itemized** (real, no demo owed) · **forbidden** (an
invariant) · **impossible**.

care: **criti** = the path a retry exists for, or a path whose failure is silent harm · **alter** =
real, rarer, loud on failure, with a workable fallback.

an `any` marks an axis a collapse makes irrelevant in that row (see `.collapses` in the dimensions
file). the `block` column is axis G; `when` stands for `given` + `when`, which share one wrapper.

## .the invariants — forbidden regions

these are rules over regions of the product, not single cells. each holds across every cell it spans.

| # | region | verdict | the invariant |
|---|---|---|---|
| I1 | jest × SOME × fail-then-pass or fail-every × snapshot | **forbidden** | a withheld mismatch of a non-final attempt must NOT count in the run's `Snapshots: N failed` tally nor the exit code (`@jest/core:1091`) |
| I2 | any × any × any × snapshot | **forbidden** | a key inside a repeatable block carries `attempt [0-9]` |
| I3 | any × EVERY | **forbidden** | skip-on-success under `EVERY` (D3) — verified absent today: `EVERY` uses the passthrough (`givenWhenThen.ts:392-394`) |
| I4 | jest × SOME × snapshot or timeout | **forbidden** | a silent fallback when jest internals are absent — a jest whose `SnapshotState` lacks `_counters` / `unmatched`, whose expect state lacks `suppressedErrors`, or whose test budget cannot be read, must throw a `MalfunctionError` that names the jest version and the absent field |
| I5 | any × SOME × fail-then-pass × any kind | **forbidden** | a red test left in the run by a non-final attempt — a later pass must leave the file green, whatever failed first |
