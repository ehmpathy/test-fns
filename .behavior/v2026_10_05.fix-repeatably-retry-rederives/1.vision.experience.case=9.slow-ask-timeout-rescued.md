# case=9 — a slow brain ask that times out is rescued (B7)

cells: 24 (jest), 25 (vitest), 26 (fail-every), 34 (vitest `then.repeatably`) · feel × care: happy × criti

## .narrative

a consumer tallies reviews through a real brain, inside
`when.repeatably({ attempts: 3, criteria: 'SOME' })`, with `jest.setTimeout(180000)`. in ci the host
is slow: attempt 1's ask hangs past 180s. today jest's own timer fails attempt 1's `useThen` test with
`Exceeded timeout`. attempt 2 asks again and passes, but the red from attempt 1 stays in the run, so
the file fails. the retry ran and still lost. the consumer gives up and reaches for `jest.retryTimes`.

after the change the wrapper owns the deadline. it races attempt 1's body against the 180s budget,
and the race ends first: the overrun becomes a caught failure, withheld like any throw. the log says
`🫧 [withheld] attempt 1 failed, a retry follows: exceeded the 180000ms budget`. attempt 2 asks again
and passes. the file is green. attempt 1's slow call may still finish in the background; its result
is thrown away.

## .bdd timeline

given('[case9] a brain ask that hangs once', () => {
  when.repeatably({ attempts: 3, criteria: 'SOME' })('[t0] tallied by the real brain', () => {
    const result = useThen('it succeeds', async () => getReviewCounts({ content }));
    then('it detects the verdict', () => expect(result.detected).toBe(true));
