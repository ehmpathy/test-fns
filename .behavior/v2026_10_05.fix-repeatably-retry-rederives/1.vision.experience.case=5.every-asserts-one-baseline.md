# case=5 — EVERY asserts every attempt against one baseline (B2, B3)

cells: 5 (jest), 12 (vitest) · feel × care: happy × criti

## .narrative

a suite runs `EVERY` with 3 attempts and a snapshot. today the `.snap` must hold three keys —
`attempt 1`, `attempt 2`, `attempt 3` — and three copies of the same bytes; any absent one hard-fails
under `--ci`. after the change the `.snap` holds one key. each attempt compares against it. a grep of
the `.snap` for `attempt [0-9]` returns zero hits. ci exits 0. the same holds on vitest, where the key
comes from the task chain rather than expect state.

## .bdd timeline

- given a `when.repeatably({ attempts: 3, criteria: 'EVERY' })` case with a `toMatchSnapshot`
  - when `[t0]` the suite runs with `-u`
    - then the `.snap` holds exactly one key for the case
    - then `grep 'attempt [0-9]'` on the `.snap` returns 0 hits (B2)
  - when `[t1]` the suite runs with `--ci`
    - then each of the three attempts matches the one key; jest exits 0 (B3)
  - when `[t2]` the received value differs on attempt 2 only
    - then attempt 2 is red and the block fails under `EVERY`
  - when `[t3]` the same file runs under vitest (cell 12), `-u` then `--run` in ci
    - then `[t0]`–`[t2]` hold: one key, zero ordinal hits, every attempt checked
