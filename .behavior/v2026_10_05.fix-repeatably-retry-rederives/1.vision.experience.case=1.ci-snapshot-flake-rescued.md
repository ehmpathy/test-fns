# case=1 — a snapshot flake is rescued, in ci and on a laptop

cells: 1 (ci), 13 (local) · feel × care: happy × criti

## .narrative

a consumer pins an LLM guard's output with a snapshot, inside
`when.repeatably({ attempts: 3, criteria: 'SOME' })`. in ci, attempt 1's brain flips a verdict and
the snapshot mismatches. jest records the mismatch without a throw. the wrapper reads the suppressed
error, withholds it, marks attempt 1 failed, and lets attempt 2 run. attempt 2's `useThen` drives the
guard again — a fresh subprocess, a fresh verdict. it matches the one baseline. the file goes green.
the run log shows attempt 1 as withheld, not as a skip.

the next day the same author runs the suite on a laptop, no `--ci`. the brain flips again on
attempt 1. the walk is identical: withheld, re-driven, green. the baseline is present, so local mode
writes no key — the `.snap` file stays byte-identical. a local flake never dirties the worktree.

## .bdd timeline

```ts
given('[case1] a guard whose verdict flips once', () => {
  when.repeatably({ attempts: 3, criteria: 'SOME' })('[t0] the guard runs', () => {
    const result = useThen('it runs', async () => runGuard()); // drives on every attempt
    then('the stdout is stable', () => {
      expect(result.stdout).toMatchSnapshot(); // key: "... when: [t0] the guard runs then: the stdout is stable 1"
    });
  });
});
```

- given a `.snap` that holds the ordinal-free key, and a guard whose attempt-1 verdict flips
  - when `[t0]` attempt 1 runs under `--ci`
    - then the mismatch is withheld; the attempt is marked failed
    - then the run tally carries no `Snapshots: 1 failed`
    - then the log carries `🫧 [withheld] attempt 1 failed, a retry follows: Snapshot ... mismatched`
  - when `[t1]` attempt 2 runs
    - then the factory runs again (count = 2)
    - then the stdout matches the ordinal-free key; the test is green
  - when `[t2]` attempt 3 runs
    - then it skips with `🫧 [skipped] prior repeatably attempt passed`
    - then jest exits 0
  - when `[t3]` the same suite runs locally, no `--ci` (cell 13), with the same attempt-1 flip
    - then `[t0]`–`[t2]` repeat as above; jest exits 0
    - then the `.snap` file is byte-identical to its prior state — no key written, none dropped
