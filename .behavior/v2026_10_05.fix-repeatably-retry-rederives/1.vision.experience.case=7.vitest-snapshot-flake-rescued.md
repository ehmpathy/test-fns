# case=7 — a vitest snapshot flake is rescued

cells: 10 · feel × care: happy × criti

## .narrative

a consumer on vitest pins an LLM guard's output with a snapshot, inside
`when.repeatably({ attempts: 3, criteria: 'SOME' })`. in ci, attempt 1 flips and the snapshot
mismatches. unlike jest, vitest throws on a mismatch, so the wrapper's catch already sees it and
attempt 2 already runs. today attempt 2 then fails anyway: its key carries `attempt 2`, which the
`.snap` never held, and `--ci` refuses to write it. the retry runs, then trips on its own name.

after the change the key carries no ordinal. attempt 2 re-drives, compares against the one baseline,
and passes. the delta from jest is the boundary that matters: on vitest the withhold is free (the
throw) and only the key is owed; on jest both are owed.

the lever that strips the ordinal on vitest is open research (vision open question 4) — vitest builds
the key from the task chain, not from expect state. this case fixes the experience the lever must
deliver, whatever the lever turns out to be.

## .bdd timeline

```ts
given('[case7] a guard whose verdict flips once, under vitest', () => {
  when.repeatably({ attempts: 3, criteria: 'SOME' })('[t0] the guard runs', () => {
    const result = useThen('it runs', async () => runGuard());
    then('the stdout is stable', () => {
      expect(result.stdout).toMatchSnapshot(); // key: "... [t0] the guard runs > the stdout is stable 1"
    });
  });
});
```

- given a `.snap` that holds the ordinal-free key, vitest in ci, and an attempt-1 flip
  - when `[t0]` attempt 1 runs
    - then the mismatch throws; the wrapper catches it and marks the attempt failed
    - then the log carries `🫧 [withheld] attempt 1 failed, a retry follows: Snapshot ... mismatched`
  - when `[t1]` attempt 2 runs
    - then the factory runs again (count = 2)
    - then the stdout is compared against the ordinal-free key — never an `attempt 2` key
    - then it matches; the test is green
  - when `[t2]` attempt 3 runs
    - then it skips; vitest exits 0
    - then the `.snap` holds one key for the case and no obsolete entry
